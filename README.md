# Painel de links

Aplicação simples em React para manter um painel privado com botões de acesso rápido para URLs frequentes.

## Funcionalidades

- Autenticação simples por senha local.
- Cadastro de novos links com nome e URL.
- Abertura dos links em nova aba.
- Remoção de links cadastrados.
- Persistência dos links no `localStorage` do navegador.
- Estilos em CSS puro, sem Tailwind.

## Como executar

```bash
npm install
npm run dev
```

Senha padrão para acesso: `painel123`.
